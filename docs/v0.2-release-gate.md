# v0.2 Release Gate

`dev/performance-banner-designer-v0.2` is an active release-candidate hardening branch, not a completed release.

Real Work acceptance has produced two permanent regression classes:

- `REAL-01` — premature rendering without category/competitor research, superficially different art directions, generic/toy-like B2B imagery and insufficient professional category fit;

User-provided visual methodology and September 2026 style research added further deterministic requirements: the pipeline must resolve **idea → presentation → emotion → visual character → style strategy → attention/typography → lighting intent** before art direction and freeze campaign grammar before scale-out.

## Next user style-example integration gate

The user's upcoming creative/banner examples remain an intentional part of v0.2 hardening.

Each example must be:
- analyzed as `REFERENCE_DNA` rather than copied;
- classified as reusable foundation grammar, contemporary overlay, execution language, attention pattern, typography role, lighting character, or one-off decorative device;
- mapped against existing Style Intelligence profiles;
- added to the library only when it contributes reusable vocabulary;
- connected to attention, typography, format resilience and `LIGHTING_INTENT`;
- evaluated for category fit and anti-generic-AI value;
- added to eval/regression cases if it exposes a systematic failure.

Do not encode any style as “high-converting” without verified performance evidence.

## Merge rule

Do not merge into `main` merely because deterministic CI is green.

Merge only when:
1. deterministic CI is green on the final head;
2. the real Work acceptance gates above pass;
3. the user's additional style-example integration has been evaluated;
4. independent rigor gates are satisfied, **or** the user explicitly accepts degraded rigor;
5. the user explicitly approves merge.

Until then:
- deterministic engineering: `ACTIVE_HARDENING`;
- real user-acceptance validation: `RETEST_REQUIRED`;
- delivery/runtime rigor: `NOT_FULLY_VALIDATED`;
- merge: `BLOCKED_BY_RELEASE_GATE`.
