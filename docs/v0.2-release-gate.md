# v0.2 Release Gate

`dev/performance-banner-designer-v0.2` is a release candidate, not a completed release, until all required gates below are satisfied.

- [x] reference-analysis contracts

- [x] controller repository hardening review
- [x] green GitHub Actions on the release-candidate branch

## Independent rigor gates

- [ ] Six visual eval cases executed by genuinely fresh visual reviewer contexts and scored against the hidden key.
- [ ] Final repository/PR reviewed by a genuinely independent reviewer context.
- [ ] Any important independent findings reconciled and CI re-run.

## Merge rule

Do not merge into `main` merely because deterministic CI is green.

Merge only when:
1. deterministic CI is green on the final head;
2. the two independent rigor gates above are satisfied, **or** the user explicitly accepts degraded rigor;
3. the user explicitly approves merge.

Until then the valid state is:

- deterministic engineering: `READY_FOR_EXTERNAL_REVIEW`;
- delivery/runtime rigor: `NOT_FULLY_VALIDATED`;
- merge: `BLOCKED_BY_RELEASE_GATE`.
