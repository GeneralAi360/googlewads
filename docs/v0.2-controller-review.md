# v0.2 Controller Review

Status: **controller review only — not an independent final review**.

## Current canonical production contract

`intake → exact commercial-job lock → research/category → idea/presentation/emotion → visual character → Style Intelligence → attention/type → policy risk → lighting intent → internal art direction → first-round exploration → optional component generation → complete banner composites → two fresh exact-artifact pre-show reviews → user selection/approval → production assets/fidelity → campaign design system → production freeze → exact render jobs → Google technical preflight → visual review → Google policy preflight → final Google-ready precheck`.

## Reconciled architecture findings

1. Meaning must be explicit before style.
2. Lighting must derive from meaning/style/AOI instead of decoration.
3. Style Intelligence needs capped currentness and provenance.
4. Typography needs runtime font/script/license/readability verification.
5. Commercial copy, CTA and canonical brand identity require locks.
6. Production asset readiness must fail closed without blocking upstream strategy or safe concept visibility.
7. The user must approve rendered visual design, not a text-only direction.
8. Product identity, campaign objective, CTA and exact commercial job are separate facts.
9. A material commercial-job change invalidates stale downstream creative work.
10. Final campaign concept count is separate from first-round exploration count.
11. Unless the user explicitly locked a direction, first-round exploration requires three materially different rendered concepts.
12. Internal recommendations, including Style Intelligence / A2 / reviewer preferences, cannot masquerade as a user lock.
13. `HERO_ASSET_CANDIDATE` is an upstream component and can never substitute for the user-facing `BANNER_COMPOSITE`.
14. A user-facing concept must already contain the primary message, commercial-job cue, CTA and brand anchor before review.
15. Concept validation must decode the exact PNG/JPEG and verify real dimensions, not trust declarative metadata alone.
16. Every first-round concept requires two distinct fresh exact-artifact reviewer contexts with no prior-verdict visibility.
17. `PRESENTATION_READY_DESIGN` requires evidence-bearing checks for semantic relevance, advertising impact, composition, typography, polish, premium category bar, non-generic identity and ad-not-slide quality.
18. Stalled/low-value image generation must be abandoned rather than becoming the workflow itself.
19. Google technical validity remains separate from Google Ads policy readiness.
20. Final local Google-ready status never guarantees actual Google approval.
